# 다락방 v9.2

운영 주소: https://ws20220403.github.io/darakbang/?v=9.2

토글 안에 독립 블록을 넣고, 하위 문서 전체를 내부 링크와 함께 복제하며, 여러 블록을 문서·토글 사이로 이동할 수 있습니다. 저장·검색·목차·Markdown·백업·복원도 하위 블록을 함께 처리합니다.

운영 소스는 `darakbang-v9-site.zip`입니다. 루트의 과거 js/css/index 파일은 운영 배포원이 아닙니다. 배포 작업이 ZIP 검증값을 확인하고 전체 파일을 한 번에 게시합니다.

이번 정적 검사와 DOM/저장 모델 시험 46개를 통과했고 실제 브라우저의 중첩 편집, 이미지, 표, 복제·이동, 저장 재열기, Undo/Redo 및 모바일 폭 배치를 확인했습니다. 이전 v9 회귀 88개는 별도 과거 기준선입니다.

새 저장 기록은 형식 4입니다. v9.2는 기존 형식 3을 읽을 수 있으나 구버전은 새 기록을 편집할 수 없습니다. 모든 앱 탭을 새로고침해 v9.2로 사용하세요. 이전 버전으로 사이트만 되돌려 새 문서를 편집하지 마세요.

Google 실제 계정의 운영 앱 로그인 및 Drive 저장 왕복은 완료 검증 전입니다. 로컬 진단에서 Google 승인 응답을 확인했으나 운영 앱의 승인 응답은 아직 받지 못했습니다. 로그인 요청은 미리 준비한 Google 클라이언트로 클릭 시 바로 시작하도록 보완했습니다.

라이브러리 출처와 라이선스는 ZIP의 THIRD_PARTY_NOTICES.md 및 vendor/licenses에 있습니다. OAuth Client ID는 공개 식별자입니다. Client Secret 및 사용자 토큰은 포함하지 않습니다.
