# 다락방 v9

Google Drive를 개인 문서 저장소로 사용하는 다락방 개선판입니다.

운영 주소: https://ws20220403.github.io/darakbang/

## 배포 자료

운영 파일은 `darakbang-v9-site.zip`에 모두 들어 있습니다. `release-manifest.json`에서 각 파일과 압축 파일의 SHA-256을 확인할 수 있습니다. GitHub Pages 배포 작업은 검증된 압축 파일을 풀어 게시합니다. 루트에 남아 있는 v8 파일들은 이전 소스 이력이며 현재 배포 자료와 구분됩니다.

`Deploy Darakbang v9` 작업은 수동 실행 또는 지정된 배포 파일 갱신으로 실행됩니다. 다른 소스 수정만으로 운영본이 바뀌지는 않습니다. 다음 배포에서도 변경한 앱을 검증하고 압축 파일·검증 목록·작업의 예상 해시를 함께 갱신하세요.

## 계정과 자료

기존 Google OAuth 웹 클라이언트와 `https://ws20220403.github.io` 출처를 유지합니다. Google 로그인 후 해당 계정의 Drive에 앱에 허용된 파일을 보관합니다. 기본 로그인 토큰은 브라우저 세션에 보관하며 서버나 이 저장소로 전송하지 않습니다.

같은 Drive 공간에서 v8과 v9을 동시에 편집하지 마세요. 전환 전 기존 Drive 폴더를 별도 보관하세요. 앱의 보관함에서 초안·저장 버전·휴지통·첨부파일을 포함한 완전 백업과 복원을 사용할 수 있습니다.

## 검증과 외부 코드

v9 로컬·모의 서비스 회귀 시험 88개 그룹이 통과했습니다. 실제 계정 검증은 이 수치와 구분합니다. 배포 압축 파일 안의 `version.json`, `THIRD_PARTY_NOTICES.md`, `vendor/licenses/`를 참고하세요. 사용자 원본 앱 코드에 새 라이선스를 부여하지 않습니다.
