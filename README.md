# 다락방 v9.2.1

운영 주소: https://ws20220403.github.io/darakbang/?v=9.2.1

기본 Google 계정 이메일을 기억해 같은 계정으로 다시 연결합니다. 계정 주소를 바꾸거나 비우면 다른 계정을 선택할 수 있습니다. 계정 이메일 기억은 로그인 상태 유지 옵션과 별개입니다. 제목을 편집할 때 상단 경로도 즉시 갱신합니다. 작은 창에서도 로그인 카드 하단에 접근할 수 있도록 내부 스크롤을 제공합니다.

v9.2의 토글 내부 독립 블록, 전체 하위 문서 복제, 여러 블록 이동과 재귀 저장·검색·목차·내보내기·백업 기능을 유지합니다.

운영 소스는 `darakbang-v9-site.zip`입니다. 루트의 과거 js/css/index 파일은 운영 배포원이 아닙니다. 배포 작업이 ZIP 검증값을 확인하고 전체 파일을 한 번에 게시합니다.

이번 정적 검사와 DOM·저장 모델 시험 50개가 통과했습니다. 실제 Google 계정에서 운영 v9.2로 시험 부모·자식 문서, 토글 서식 내용, 이미지와 첨부파일을 저장했습니다. 새로고침 및 별도 localhost v9.2.1 앱에서도 같은 Drive 문서를 복원했으며 다운로드한 첨부파일의 SHA-256이 원본과 일치했습니다. 전송·호환 파일 대기와 기본 계층 진단 이상은 0건이었습니다. v9.2.1 운영 게시 후 확인 결과는 별도 배포 보고서로 기록합니다.

새 저장 기록은 형식 4입니다. v9.2 계열은 기존 형식 3을 읽습니다. 모든 앱 탭을 새로고침해 최신판을 사용하세요. 사이트만 v9.1로 되돌려 새 문서를 편집하지 마세요.

OAuth 공개 대상은 기존 개인 테스트 계정 설정을 유지합니다. 사이트 배포와 OAuth 전체 사용자 공개는 별개입니다. 권한 범위는 변경하지 않았습니다. 라이브러리 출처와 라이선스는 ZIP의 THIRD_PARTY_NOTICES.md 및 vendor/licenses에 있습니다. 사용자 문서, 개인 계정 이메일, 토큰 및 Client Secret은 게시 ZIP에 포함하지 않습니다.
